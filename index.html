RExtract

Welcome to RExtract, the data extraction tool for REminiscence on the Atari ST (aka Flashback). Drop your four Amiga installations below, extract the data and put the resulting DATA file next to FLASHBAK.TOS

Drop the four disk images here

Disk images must be .ipf, .adf or .adz format

    What this does

    The Atari ST port of Flashback plays the Amiga game's own data files. This reads them off your disk images, renames them the way the ST's filesystem needs, and gives you back a DATA folder to put beside FLASHBAK.TOS.

    Everything happens in this browser. Your disk images are never uploaded, and there is nothing here to upload them to: the page is a static file and the work is done by the tab you are looking at. You need your own copy of the Amiga release — this supplies no game data and never will.
